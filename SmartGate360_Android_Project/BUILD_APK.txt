ANDROID STUDIO BUILD STEPS

1. Install Android Studio on a computer.
2. Extract SmartGate360_Android_Project.zip.
3. Android Studio > Open > select the extracted project folder.
4. Accept the Gradle sync and SDK installation prompts.
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Find app/build/outputs/apk/debug/app-debug.apk.

The generated debug APK is for testing only. A production release needs a release signing key, backend authentication, security review, and approved company integration.
