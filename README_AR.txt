SmartGate 360 — مشروع Android تجريبي أصلي

مهم: هذا مجلد مصدر Android Studio وليس ملف APK جاهزاً. لم يتم تجميع APK في بيئة الإنشاء الحالية لعدم توفر Android SDK وGradle وعدم إمكانية تنزيلهما من الإنترنت هنا.

طريقة استخراج APK:
1) افتح Android Studio على كمبيوتر.
2) اختر Open وافتح مجلد SmartGate360_Android_Project بعد فك ضغطه.
3) اسمح لـ Android Studio بتنزيل Gradle وAndroid SDK المطلوبة عند توفر الإنترنت.
4) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) بعد نجاح البناء سيظهر زر Locate أو المسار:
   app/build/outputs/apk/debug/app-debug.apk
6) انقل app-debug.apk إلى هاتف Android وافتحه، واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.

المزايا:
- واجهة عربية وإنجليزية.
- شاشة دخول فرد الأمن.
- محاكاة تسجيل دخول وخروج المواد وقراءة RFID.
- تحقق تجريبي من التصريح ومطابقة المواد.
- سجل حركات محلي وتصدير CSV.

حدود النسخة:
- لا تتصل بقارئ RFID فعلي أو كاميرا أو ERP/WMS أو قاعدة بيانات مركزية.
- المصادقة تجريبية وليست مناسبة للاستخدام الأمني الحقيقي.
- لا تتحكم في حاجز البوابة.
- لا تستخدم بيانات حقيقية للشركة أو الموظفين أو المركبات.
